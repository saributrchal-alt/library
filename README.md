# ห้องสมุดวัดพุทธอุทยานนาเทิง

เว็บห้องสมุดที่ `library.nathoeng.com` เป็นโครงการแยกจากเว็บวัด `watt.nathoeng.com` แต่จะใช้สมาชิกวัดและบัตรสมาชิกใบเดิมในระยะต่อไป

## รุ่นแรก

- หน้าแรกเรียบง่าย มีช่องค้นหาหนังสือหนึ่งช่อง
- ค้นจากชื่อ ผู้เขียน หรือหมวดหมู่ และเปิดรายละเอียดหนังสือ
- ยังไม่เปิดส่งคำขอยืมจนกว่าจะเชื่อมสมาชิกวัดและกำหนดสิทธิ์เจ้าหน้าที่อย่างปลอดภัย
- ไม่มีข้อมูลหนังสือตัวอย่างที่อาจทำให้เข้าใจว่าเป็นทะเบียนจริง

## เชื่อมข้อมูล

ตั้ง `supabaseUrl` และ **anon key** ใน `config.js` หลังสร้างตาราง `books` พร้อมนโยบาย RLS ให้อ่านเฉพาะหนังสือที่เผยแพร่ได้ ตารางต้องมีฟิลด์ `id,title,author,description,category,isbn,available_copies,total_copies,is_active` (ดู `schema.sql`) ห้ามใส่ service-role key ในโค้ดเว็บ

การเชื่อมสมาชิกวัดต้องตรวจสอบฐานข้อมูลและวิธี login ของเว็บวัดก่อน จากนั้นสร้างบริการฝั่งเซิร์ฟเวอร์เพื่อยืนยันสมาชิกและรับคำขอยืม ห้ามเชื่อถือหมายเลขสมาชิกหรือสิทธิ์เจ้าหน้าที่ที่ส่งจากเบราว์เซอร์โดยตรง
