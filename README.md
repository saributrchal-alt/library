# ห้องสมุดวัดพุทธอุทยานนาเทิง

`library.nathoeng.com` เป็นเว็บห้องสมุดแยกโปรเจกต์จากเว็บวัด โดยใช้ทะเบียนสมาชิกและบัตรสมาชิก EAN-13 เดิมของ `watt.nathoeng.com`

## หน้าเว็บ

- `/` ค้นชื่อเรื่อง ผู้เขียน หมวดหมู่ และเปิดรายละเอียดหนังสือ
- `/admin.html` เจ้าหน้าที่วัด (role `admin`) เพิ่ม/แก้ข้อมูลชื่อเรื่อง รับตัวเล่มเข้า ยืม คืน พักซ่อม สละออก และนำกลับใช้
- ใช้เครื่องยิงบาร์โค้ด USB แบบ keyboard wedge ที่ส่ง Enter หลังสแกนในช่อง ISBN, บัตรสมาชิก หรือรหัสตัวเล่ม
- ISBN ใช้กับข้อมูลชื่อเรื่อง หลายตัวเล่มใช้ ISBN เดียวกันได้ ตัวเล่มแต่ละเล่มใช้รหัสภายใน `NTL-xxxxxxxx` ที่ระบบสร้าง หรือรหัสที่เจ้าหน้าที่กรอก
- กดค้นข้อมูล ISBN เพื่อดึงชื่อ ผู้เขียน และภาพจาก Open Library แล้วตรวจแก้ก่อนบันทึก; สามารถใส่ URL ภาพ HTTPS ด้วยตนเอง

## ตั้งค่าก่อนใช้จริง

1. ใช้ **Supabase project เดียวกับเว็บวัด** และรัน [`schema.sql`](schema.sql) ใน SQL Editor หลังตรวจสอบตารางเดิม/สำรองข้อมูล ตาราง `member_card_numbers` และ `members.membership_status` ต้องมีอยู่แล้วในเว็บวัด
2. ที่ Vercel โปรเจกต์ `library` ตั้ง `SUPABASE_URL`, `SUPABASE_SECRET_KEY` และ `SESSION_SECRET` ให้ตรงกับโปรเจกต์เว็บวัด (`SESSION_SECRET` เป็น secret ฝั่งเซิร์ฟเวอร์เท่านั้น)
3. เพิ่ม route `library-session` ใน `api/line-login.js` ของเว็บวัดแล้ว ฟังก์ชันนี้อ่าน cookie login ของเว็บวัด ตรวจสมาชิกในฐานจริง และออกโทเค็นอายุ 3 นาทีเฉพาะห้องสมุด
4. กรอก Supabase URL และ **anon key** ใน `config.js` สำหรับการค้นสาธารณะเท่านั้น ห้ามใส่ secret/service-role key ในไฟล์เว็บ
5. ตรวจจริงด้วยบัตรผู้ดูแล บัตรสมาชิกทั่วไป ISBN หนึ่งรายการ ตัวเล่มสองเล่ม และขั้นตอนยืมคืน

Admin API จะปิดด้วย `503` จนตั้งค่าฝั่งเซิร์ฟเวอร์ครบ และตรวจสิทธิ์ admin ในฐานสมาชิกทุกครั้งที่เรียกใช้งาน การเปลี่ยนสถานะตัวเล่มและยืมคืนทำใน SQL transaction พร้อมล็อกแถวกันยืมซ้ำ

## งานถัดไป

คำขอยืมจากสมาชิกด้วยตนเอง, คิวตรวจอนุมัติ, การจัดส่งพร้อมพิมพ์ฉลาก, การแจ้งเตือน, การนับสต็อก, สิทธิ์เจ้าหน้าที่ห้องสมุดแยกจาก admin วัด และเงื่อนไขระยะเวลายืม ยังไม่ได้เปิดใช้งาน
